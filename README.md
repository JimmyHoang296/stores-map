# Bản đồ chuỗi bán lẻ Việt Nam

Bản đồ so sánh vị trí cửa hàng của 6 chuỗi bán lẻ tại Việt Nam: **Bách Hoá XANH, WinCommerce (WinMart), Circle K, GS25, FamilyMart, AEON MaxValu**.

🔗 **Xem online:** https://jimmyhoang296.github.io/stores-map/

## Tính năng

- Bản đồ nền chi tiết (đường phố, công trình) dùng vector tile OpenMapTiles
- Tự động gom các cửa hàng gần nhau thành 1 chấm khi zoom xa, tách lẻ khi zoom gần
- Bật/tắt từng chuỗi, tìm kiếm theo tên/địa chỉ cửa hàng
- Thống kê số lượng cửa hàng theo từng tỉnh/thành (có thể bấm vào tỉnh để khoanh vùng)
- Tự đổi giao diện sáng/tối theo hệ thống

## Dữ liệu

File `index.html` là bản đồ hoàn chỉnh, tự chứa (không cần máy chủ backend). Dữ liệu cửa hàng được lấy trực tiếp từ website/API công khai của từng chuỗi và cập nhật định kỳ.
